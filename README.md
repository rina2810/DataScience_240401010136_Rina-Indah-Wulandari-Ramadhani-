## Deskripsi Repository

Repository ini berisi kumpulan notebook praktikum Data Science dari Pertemuan 1 sampai Pertemuan 7. Setiap notebook berisi materi, contoh implementasi menggunakan Python, serta kesimpulan dari praktikum yang telah dilakukan.

---

## Daftar Praktikum

### Pertemuan 1 - Pengenalan Data Science
Mempelajari konsep dasar Data Science, manfaatnya, dan penggunaan Python untuk pengolahan data sederhana.

### Pertemuan 2 - Struktur Data Python, NumPy & Pandas
Mempelajari struktur data Python, penggunaan NumPy untuk komputasi numerik, dan Pandas untuk pengolahan data.

### Pertemuan 3 - Data Cleaning: Missing Value, Outlier & Ekstraksi Data
Mempelajari proses pembersihan data, penanganan missing value, dan ekstraksi data berdasarkan kondisi tertentu.

### Pertemuan 4 - Statistika Dasar & Analisis Data
Mempelajari analisis statistik dasar seperti mean, median, nilai maksimum, dan nilai minimum.

### Pertemuan 5 - Visualisasi Data
Mempelajari pembuatan grafik menggunakan Matplotlib untuk membantu proses analisis data.

### Pertemuan 6 - Persiapan Data
Mempelajari normalisasi dan persiapan data sebelum digunakan dalam proses machine learning.

### Pertemuan 7 - Pengantar Machine Learning: Regresi Linier
Mempelajari konsep dasar machine learning menggunakan metode regresi linier untuk melakukan prediksi.
